# Callout

La frase que un carrusel o una página quiere que se recuerde, en `cita` (Libre Caslon Text cursiva), con filete de latón y la norma que la respalda en `radicado` (mono, `nogal`).

- El consumidor da `children` (una o dos frases cortas) y `cite` (artículo y código exactos, p. ej. "Art. 411, Código Civil").
- Solo cita normas que el equipo haya verificado; si no hay norma, omitir `cite`.
- No: más de un Callout por pieza, comillas tipográficas añadidas a mano.
