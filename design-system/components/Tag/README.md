# Tag

Etiqueta corta en píldora para áreas de práctica y estados de un caso. `nogal` (por defecto) marca el área ("Familia", "Tránsito"); `tinta` información ("Consulta virtual"); `exito`, `aviso` y `error` son estados y siempre llevan la palabra ("Fallo favorable", "Plazo: 10 días", "Documento incompleto").

- El consumidor da `children` (1–3 palabras) y opcionalmente `icon`.
- No: usar un tono de estado como decoración, ni tags de solo color.
