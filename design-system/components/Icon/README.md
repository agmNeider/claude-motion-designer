# Icon

Ícono lineal de 24×24 con trazo de 1.5px que hereda `color` (`currentColor`). Por defecto va en `nogal`, dentro de un disco `nogal-soft` (clase `nar-disc`) cuando encabeza un servicio.

- El consumidor da `name` (uno de `Icon.names`), y opcionalmente `size` y `label` (solo si el ícono va sin texto al lado).
- Mapeo de servicios: familia → `users`, tránsito → `car`, documentos → `file-text`, certificados → `file-badge`, asesoría → `scale`, derecho público → `landmark`, penal → `gavel`, contacto → `phone` y `map-pin`.
- No: emojis en piezas gráficas, íconos rellenos, mezclar otro set.
