# ServiceCard

Tarjeta de un servicio de la firma: disco con ícono, área en antetítulo, título en `heading` (Libre Caslon Display) y la lista de subservicios con viñeta de latón. Sale de las piezas "Servicios jurídicos y trámites" y "Trámites de tránsito".

- El consumidor da `icon`, `area`, `title` y `items` (3–6 líneas cortas, sustantivos: "Tutelas", "Certificado RUNT"). `footer` admite un `Button` quiet o un `Tag`.
- En grilla, todas las tarjetas de una fila llevan el mismo número aproximado de ítems.
- No: párrafos largos dentro de la tarjeta, más de un botón, sombra sobre superficie lisa (usar solo el borde `line`).
